# Local delivery reference

The bundled craft references contain the adopted methods. External authority links are optional verification/update sources, not required to recover this workflow.

For captions, preserve speech meaning, timing, speaker context and relevant non-speech sound. Inspect readability, contrast and placement at delivery size. Avoid rapid high-contrast flashes; a visual impression does not establish flash-threshold compliance. Use grapheme-aware segmentation for animated text; a Unicode code point or UTF-16 unit is not necessarily a whole displayed character. Preserve language-specific line breaking and bidirectional text. Do not split combining marks or emoji sequences by a naive character counter.

After Effects export support depends on the installed version and render modules. Inspect the real Render Queue/Output Module or Media Encoder options. Choose codec, alpha, bit depth, frame size/rate and audio from the deliverable specification, render an owned short segment, then inspect that file. A missing H.264 module is not a reason to claim direct Render Queue support; use an approved available export route. Keep a suitable master when downstream transcoding is required.
