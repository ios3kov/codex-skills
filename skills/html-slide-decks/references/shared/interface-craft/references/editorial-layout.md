# Editorial layout

Use for content-led page composition, catalogs, slide sequences or linked screens. This reference owns visual relationships and reading rhythm. Keep the selected interface, slide, document or PDF workflow responsible for format, geometry, navigation, export and verification.

## Compose with real content

Inventory the required text, images, tables, captions, credits and their dependencies. Establish whether the reader scans, studies, follows a speaker or compares objects. Use representative dense and sparse content before committing to a recurring layout; placeholder blocks can hide the actual fitting problem.

Choose alignment anchors, margins, columns, gutters and recurring roles that suit the content. A grid is a useful structure; freeform or symmetric composition can also be deliberate. Baseline alignment can unify comparable text columns, while different heading sizes, images or captions may need optical adjustment. Do not force every element onto the same grid increment.

Balance visual weight through scale, contrast, placement and empty space. Keep captions and credits associated with the correct image, and avoid ambiguous reading order. Crop around the image's function and protected content. Empty space can clarify grouping, but must not displace required information or make a task unnecessarily laborious.

## Design the sequence

For a multi-page artifact, map content groups and dependencies before styling each page. Reuse a few appropriate layouts for recurring content and make section changes recognizable. Inspect the sequence as thumbnails and at reading size: where does density rise, where does an image change the argument, and where can the reader orient themselves?

Vary density when it improves comprehension; no fixed count of dense pages or mandatory visual breather applies. A catalog may intentionally repeat a comparison layout. Speaker-led slides may give one visual more space; a reading-first document may carry more explanation. Distribute complete content across additional pages when necessary rather than silently abridging it.

For a bound publication, evaluate facing-page relationships, reading direction, binding and content near the gutter. For a single-page screen or PDF viewed one page at a time, evaluate that experience as well. Equal margins, generous inner margins or single-page composition can be correct. Derive bleed, color management, effective image resolution and export profile from the actual production specification; do not impose universal print numbers on digital output.

## Reconcile design and verification

Keep image/text roles, repeated labels and navigation consistent across the sequence. Use the shared typography reference for type roles and rendered text. Check worst-case content, caption association, clipping and hierarchy in the actual output; a grid diagram alone does not establish readability or production readiness.

For browser decks, retain `html-slide-decks` stage fitting and navigation. For requested PowerPoint, Word or PDF deliverables, retain their native creation and rendered-review workflows. A request to improve layout does not authorize converting the format or rewriting approved copy.
