# Character continuity

Turn the approved character into a reusable production specification. Keep identity, scene variation and visual style as separate decisions.

1. Locate the approved character image/sheet and current brief. Resolve whether the target is precise visual identity, a fictional recurring character or a loose family of designs. Do not invent missing defining traits.
2. Read [identity and shot state](references/identity-and-shot-state.md). Record locked traits, allowed variations and changes that belong to the story; identify a canonical approved version and its reference pack.
3. Reuse a stable identity anchor across shots. Add pose, expression, camera, lighting and scene state separately. Use only reference/edit controls actually available in the selected generation tool; a seed or the words "same character" do not prove continuity.
4. Compare actual outputs with the approved reference at thumbnail, delivery size and detail scale. For video, inspect motion and shot boundaries as well as stills. Classify the drift before choosing a local repair.
5. Retain the original and approved variants. Record the changed parameter, parent output and retest result; a repair must preserve unaffected approved traits.

This skill owns character identity and per-shot appearance, not general shot direction or every delivery check. Use `motion-storytelling` for staging/timing and `media-production-control` for the shared asset ledger and final generated-media review. Use an available image/video generation skill and tool for actual generation or edits; this skill does not install a model, identity adapter or provider integration.

The handoff includes the approved references, identity anchor, variation rules, current shot state and unresolved drift. Preserve exact anchor wording or a precise pointer through `context-discipline`; do not repeat the full character bible in every working note.
