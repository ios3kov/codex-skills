# Targeted Questionnaire

Produce questions the respondent can answer and the user can act on.

## Establish the gap

Reuse the conversation, confirmed decisions, and relevant supplied materials. Consult earlier context only when missing history would materially change the questionnaire.

Identify the respondent's role and relevant knowledge, the decision or action the answers should enable, and the remaining facts only that person can supply. Resolve information already available in the materials; distinguish confirmed facts from assumptions.

Ask up to three concise questions in one exchange only when the audience or intended outcome remains consequentially unclear. Ask the user about the recipient and purpose; put subject-matter gaps into the questionnaire for the person who knows. When context is sufficient, draft immediately.

**Complete when:** the audience, intended outcome, known constraints, and material information gaps are clear enough to draft without inventing commitments.

## Draft

Start with a short purpose and only the background the respondent needs. Put consequential questions first and group them by theme when useful. Each question covers one subject and leaves space for an answer. Use neutral wording and the respondent's vocabulary; offer choices only when they help and leave room for uncertainty.

Respect the requested length. Accept partial answers and “I don't know.” Include an open question for relevant omissions when useful. For an existing brief, update affected questions and preserve confirmed answers and unrelated content.

Use dates, budgets, scope, deliverables, effort estimates, and available materials only when confirmed. Ask about missing constraints if they affect the intended decision. Request only necessary information; credentials and unrelated personal data do not belong in a brief.

**Complete when:** every material gap has a question, known facts are not asked again, and the draft makes no unsupported commitments.

## Deliver

Honor the requested format and destination. For an explicit chat-only request, return the complete draft in chat using the available writing format.

For a requested file, load the applicable artifact-format and persistence instructions before creating it. For a reusable standalone brief with no specified format, use the available document or page workflow and its established destination. Preserve existing file identity when updating; follow required rendering and verification. If saving is unavailable, report that limitation and provide the complete draft in chat without claiming a file was saved.

Drafting does not authorize sending, publishing, sharing, or invitations. Perform a person-directed action only when explicitly authorized and through the applicable recipient-resolution and application workflow.

**Complete when:** the full draft is delivered in the requested form, or the precise saving limitation and the complete text are provided; any unperformed sending remains explicit.
