# Reference analysis

Inspect the reference itself at the depth needed for the decision. A thumbnail can support broad composition observations, not precise text, lens metadata or full-film timing. For a video/audio reference establish the viewed/listened range and timebase. If the actual material is unavailable, keep analysis provisional and request the missing material before reference-specific claims.

Separate observable description from interpretation: what is present and how it changes versus the inferred emotional or narrative function. Distinguish dolly from zoom when evidence supports it; lens choice, lighting setup and creative intent are often hypotheses. Captions or a fluent model description do not replace inspecting the referenced content.

Extract a useful production packet:

| Dimension | Concrete observations or decisions |
|---|---|
| Composition | Focal subject, hierarchy, crop, negative space, scale, perspective |
| Light/material | Direction, softness, falloff, shadows, reflections, texture |
| Color | Dominant/accent roles, temperature, saturation, contrast, approved palette constraints |
| Typography | Role, placement, size/read time and hierarchy; detailed browser type uses interface-craft |
| Motion/edit | Action, camera purpose, holds, pacing, transition function and audio relationship |
| Sound | Voice energy/pace, music density/instruments, ambience, key effects, silence |
| Identity/product | Approved source details that must remain exact, and which material is only inspiration |

Translate adjectives into implementable choices. "Premium" could mean a controlled highlight, restrained palette, slow intentional reveal and sparse sound, but those are proposed choices rather than facts about the reference. Resolve conflicting references by assigning their roles instead of averaging incompatible instructions.

Use a compact map: reference ID/time or region → observed feature → intended function → proposed adaptation → acceptance check. Preserve the user's authorized fidelity scope: a faithful conversion of their own artwork differs from broad stylistic inspiration. Do not import incidental reference logos, copy, metrics or a person's identity into a new deliverable. Keep known usage constraints with the asset record without inventing a legal conclusion.

For detailed shot timing, hand the packet to motion-storytelling; for a mix, to audio-production. Compare the resulting work against the approved brief and extracted principles, not a vague similarity score. Mark deliberate differences and unresolved observations.
