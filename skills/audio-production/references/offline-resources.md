# Local loudness and delivery reference

The bundled mix-and-delivery reference is the operational guide. BS.1770 describes loudness/true-peak measurement algorithms; EBU R 128 defines a broadcast normalization framework. They are not a universal target for every delivery platform.

Record integrated loudness, relevant short-term/momentary behavior, true peak, channel layout, duration and measurement tool/settings for the actual delivered file. Use a documented meter appropriate to the requested standard; ordinary sample peak is not true peak. Verify sync and audible voice/music/effect balance by listening as well as measuring. For a supplied R 128 broadcast target, -23 LUFS is the usual integrated program reference, but actual tolerances, true-peak limits and short-form rules come from the applicable supplied delivery specification. If no target is available, preserve headroom, avoid destructive normalization and report that compliance is unverified. Do not invent a streaming platform's current normalization or encode limits.
