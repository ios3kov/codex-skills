# Mobile references and Mobbin

Use `design-reference-research` for the search/inspect/deduplicate/synthesis loop when available. This reference adds mobile context and provider behavior; it does not create a second research workflow.

## Record the mobile context

For a selected example record app, platform, capture/version date if exposed, screen or flow identity, locale/theme, device/window context, and whether the evidence is a still image, recorded interaction, or inspected live behavior. Unknown context remains unknown. Compare complete task sequences when the design decision concerns onboarding, authentication, purchasing, permissions, editing, or recovery; isolated successful screenshots cannot establish those paths.

Look for the mechanism that resolves the task: input/keyboard placement, navigation and return, changing list state, explanation timing, permission denial, or save recovery. Distinguish its platform chrome from its brand-specific visual language. Two screenshots from one screen/flow family are useful only when they expose a new decision or state; do not count a second crop or color variant as a new direction.

## Mobbin access

Mobbin is an optional research source, not a required implementation dependency or reusable asset library. Public [pricing](https://mobbin.com/pricing) and [MCP information](https://mobbin.com/mcp) inspected on 2026-10-10 list limited free access and paid access to flows/animations/search/MCP. Recheck current plan/tool availability before a live provider task; do not infer account access from those public pages.

Use an exposed, authorized connector and its discovered schema if present, or permitted browser access. Do not install/configure MCP, start a subscription, upload private brief material, or simulate tool results merely to use this method. Without usable access, use supplied captures, owned app flows, official examples, and permitted open-web evidence; state the evidence type.

A reference app's popularity or presence in a catalog does not prove that its pattern is usable, accessible, current, or conversion-optimal. Adapt the mechanism to this product and verify it. Research access does not grant permission to reuse another app's screenshot, logo, font, or artwork in the delivered interface.
