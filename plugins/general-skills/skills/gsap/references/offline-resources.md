# Local GSAP API baseline

Inspect the installed version, imports and plugins. In GSAP 3, gsap.to(target, vars), gsap.fromTo(target, fromVars, toVars) and gsap.timeline() cover ordinary sequences. Timeline position parameters control overlap; do not replace them with unrelated timers. Use a context/lifecycle owner where supported and revert/kill only owned animation on disposal. Register only plugins actually used. ScrollTrigger's trigger, start/end, scrub and pin describe different behavior; refresh after relevant layout changes, not every frame. matchMedia/reduced-motion handling must preserve a usable static state. Verify these names against local declarations before adding code to a different major version. This guide is original; external links are optional source/update credits, not an installation route.
