# Local Three.js implementation baseline

Inspect the installed revision and module declarations. A conventional scene owns a Scene, camera, renderer and explicitly managed animation loop. A mesh combines geometry and material; resizing requires consistent renderer dimensions, camera aspect and projection update. Use the installed revision's color-space and tone-mapping APIs rather than copying a different revision's property names. Load approved local GLTF/media files through the project's actual loader paths. Track disposal of owned geometry, materials, textures, controls and renderer resources; removing a mesh alone does not release GPU resources. Confirm render output and interaction in the target browser. This original baseline preserves the method without online documentation; it does not bundle the Three.js runtime or authorize changing the project's version.
